This voicebank is made with one of the most traditional methods. It's intended for OpenUTAU. With the voice of Furukawa Nagisa from CLANNAD. 
This repo will be updated if I got better results on this project later. Time unknown.
If you haven't used OpenUTAU before, you can install it for free here: https://www.openutau.com/
Note that UTAU and OpenUTAU are different. The former has a region lock which makes it hard to use for people outside Japan. The later, as its name suggests, is completely open source and free, run by a diverse community of people all around the world.
This voicebank, as a part of it, is completely open source too. And as the sample quality is actually poor inside this bank, please feel free to modify them and/or change them for better samples so that the voicebank can perform in a better way. If you do so, please open source it too for the CLANNAD community. There's no need to mention me or this repo, though I would be happy if you do (^> <^)
